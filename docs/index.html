Antigravity CLI en Termux

Instalación nativa para Android ARM64 (aarch64). Sin proot, sin VMs, sin Cloud Shell.

Ver en GitHub Guía de instalación

Instalación rápida

Abre Termux y ejecuta:

pkg update && pkg upgrade -y
pkg install git curl tar -y
git clone https://github.com/sebastianl1/antigravity-termux.git
cd antigravity-termux
bash install.sh

¿Es tu primera vez con Termux? Consulta la guía para principiantes.

Características

100% nativo

Bootstrapper compilado para Android/Bionic, sin emuladores.

Engine glibc parcheado

Compatible con Termux: DNS y TLS configurados automáticamente.

Integración con opencode

Usa los modelos de Antigravity desde opencode con un comando.

Instalación con un clic

Script interactivo que verifica, instala y configura todo.

Uso

agy              # Iniciar la CLI interactiva
agy login        # Autenticar con Google (OAuth)
agy --version    # Verificar la versión
agy update       # Actualizar a la última versión
